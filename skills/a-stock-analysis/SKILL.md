# A股个股深度分析 v3.0

## 前置条件

- Python 3（脚本仅用标准库 `urllib`、`json`、`re`）
- 网络可访问东方财富、腾讯行情、新浪财经

## v3.0 架构

**行情 3 层 fallback**：东方财富(push2) → 腾讯(qt.gtimg.cn) → 新浪(hq.sinajs.cn)，盘后自动降级。

**解耦架构**：每个 API 独立 try/catch，互不阻塞。

**新增维度**：个股新闻(新浪)、龙虎榜(东财 datacenter)、股东人数变化(F10)、主营业务构成(F10)。

## 工作流程

### 第一步：获取数据

```bash
python skills/a-stock-analysis/scripts/fetch_stock_data.py <股票代码>
```

脚本输出 10 个维度：大盘指数、行情(含来源标注)、财务(EPS/BPS/ROE/净利润)、估值(PE/PB/ROE计算值)、日线K线(200条)、技术指标(MA/RSI/ATR/VWAP/区间位置)、成交量(量比/均量)、主力资金流向(近5日/⚠️盘后不可用)、个股新闻(8条)、龙虎榜(10日)、股东人数(6期)、主营业务(Top 5)。

### 第二步：多维分析

**分析必须基于脚本实际数据，不可编造。** 按以下维度逐层展开：

- **0. 大盘环境**：三大指数涨跌方向、相对位置，判断"有利于/不利于个股"
- **1. 基本面**：EPS趋势、ROE水平(<5%低/5-15%中/>15%高)、季度利润变化、分红。评分：优/良/中/差
- **2. 估值**：PE(TTM) vs 行业中枢(PE<15低估/15-30合理偏低/30-60合理偏高/60-100高估/>100极度高估)、PB vs ROE匹配度(PE/ROE<1=低估)、股息率 vs 无风险利率
- **3. 技术面**：均线排列(多头/空头/交叉)、支撑位(MA20/MA60/60日低点/VWAP)和压力位(MA5/MA10/60日高点)各给具体价格、RSI(>70超买/<30超卖)、量比含义(放量上涨=强势/放量下跌=恐慌/缩量横盘=观望)、60日区间位置
- **4. 主力资金**：近5日净流入总额、近3日趋势、连续流入/流出天数、大单vs小单对比(主力买+散户卖=吸筹、主力卖+散户买=出货)、与股价走势对比判断量价配合
- **5. 入场时机**：当前判断(适合/不适合/等待)、分批建仓价格区间和仓位、等待条件(明确价格/信号)、止损位(支撑位下方3-5%)
- **6. 新闻舆情**：重大事件(中标/业绩/政策)、情绪判断(正面/负面/中性)、关联度(实质性vs市场情绪)
- **7. 龙虎榜**：上榜频率、资金博弈(买入vs卖出)、机构参与度(席位数量)、游资or机构特征
- **8. 股东人数**：筹码集中度趋势(减少=集中利好/增加=分散利空)、户均市值、变化幅度>10%重点关注、与股价走势对比
- **9. 主营业务**：营收结构、盈利质量、政策催化业务占比(避免概念炒作)、收入集中度

### 第三步：输出报告

报告含以下章节：大盘环境、核心数据速览、基本面、估值、技术面(均线+支撑压力位表+RSI/量比)、主力资金(逐日表+结构判断)、入场时机(含价格区间+仓位+止损)、舆情新闻、龙虎榜、股东人数筹码变化、风险提示。

## 注意事项

1. 数据驱动，不编造；大盘优先，先看大盘再看个股
2. 技术术语用通俗语言解释；PE>500时转看PB/ROE/行业周期
3. "能买吗"给有条件判断，不给简单答案；支撑/压力位给具体价格
4. 盘后可用(腾讯/新浪 fallback)，但主力资金流向盘后不可用，标注数据来源
5. 新闻关注公告/中标/业绩预告等实质性内容，忽略市场情绪类资讯
6. 龙虎榜非所有股票都有，无上榜记录静默跳过
7. 股东人数关注趋势，结合股价位置判断"利好出尽"风险
8. 主营业务用于判断政策催化占比，避免概念炒作
