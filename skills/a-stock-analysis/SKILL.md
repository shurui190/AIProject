# 个股深度分析 v4.0（A股 + 美股）

## 前置条件

- Python 3（脚本仅用标准库 `urllib`、`json`、`re`、`ssl`）
- 网络可访问东方财富、腾讯行情、新浪财经、纳斯达克官网

## v4.0 架构

**市场自动识别**：字母开头的代码（MU、SPCX、BRK.B）按美股处理；数字代码按A股处理。

**行情多层 fallback**：
- A股：东方财富 → 腾讯 → 新浪
- 美股：东方财富(105/106/107) → 腾讯(usXXX) → 新浪(gb_XXX)，并自动合并三源字段
  （东财给市值/PE动态，腾讯给换手率/成交额，新浪给52周高低）

**K线双源**：美股优先东财 push2his（含当日盘中bar），失败时自动切换纳斯达克官网
  EOD历史数据（约260根，不含当日盘中bar，技术指标基于最近收盘）。

**解耦架构**：每个 API 独立 try/catch，互不阻塞；美股缺失维度（财务明细/龙虎榜/
  股东人数/主营业务/新闻）输出缺省提示，不崩溃。东财接口偶发限流时自动切换备用主机。

## 工作流程

### 第一步：获取数据

```bash
python skills/a-stock-analysis/scripts/fetch_stock_data.py <代码> [--json]
# A股示例: python .../fetch_stock_data.py 600111
# 美股示例: python .../fetch_stock_data.py MU
#          python .../fetch_stock_data.py SPCX
```

脚本输出维度（A股10项全量）：大盘指数、行情(含来源标注)、财务(EPS/BPS/ROE/净利润)、
估值(PE/PB/ROE)、日线K线、技术指标(MA/RSI/ATR/VWAP/区间位置)、成交量(量比/均量)、
主力资金流向(近5日)、个股新闻、龙虎榜、股东人数、主营业务(Top 5)。
美股输出：大盘指数(道琼斯/纳斯达克/标普500)、行情(含52周区间/市值/PE)、K线、
技术指标、成交量、估值(PE)，其余维度缺省并在 warnings 中说明。

### 第二步：多维分析

**分析必须基于脚本实际数据，不可编造。** 美股缺失维度用财报/公开信息补充时，
必须注明数据来源。按以下维度逐层展开：

- **0. 大盘环境**：三大指数涨跌方向、相对位置，判断"有利于/不利于个股"
- **1. 基本面**：EPS趋势、ROE水平、季度利润变化、分红（美股用财报/公开报道补充）。
  评分：优/良/中/差
- **2. 估值**：A股按 PE(TTM) vs 行业中枢 + PB/ROE匹配 + 股息率 vs 无风险利率；
  美股按行业特性选锚（周期半导体看远期PE和PB/ROE，成长股/亏损股看PS、EV/EBITDA），
  亏损股 PE 无意义时明确说明
- **3. 技术面**：均线排列、支撑位(MA20/MA60/60日低点/VWAP)和压力位(MA5/MA10/
  60日高点)各给具体价格、RSI(>70超买/<30超卖)、量比含义、60日区间位置
- **4. 主力资金**：近5日净流入总额、近3日趋势、连续流入/流出天数、大单vs小单对比。
  美股此维度依赖东财接口，不可用时标注"暂不可用"并跳过
- **5. 入场时机**：当前判断(适合/不适合/等待)、分批建仓价格区间和仓位、等待条件、
  止损位(支撑位下方3-5%)
- **6. 新闻舆情**：美股需另行检索（财报/公告/行业事件/监管/解禁），标注来源
- **7. 龙虎榜**：A股专属；美股不适用
- **8. 股东人数**：A股专属；美股不适用（可参考机构持仓/13F）
- **9. 主营业务**：A股F10；美股用财报分部数据补充（如星链/发射业务占比）

### 第三步：输出报告

报告含以下章节：大盘环境、核心数据速览、基本面、估值、技术面(均线+支撑压力位表+
RSI/量比)、主力资金(有数据时给逐日表)、入场时机(价格区间+仓位+止损)、舆情新闻、
风险提示。美股报告需注明：K线数据截至日、行情来源、数据时间。

## 美股支持说明（v4.0 新增）

1. **代码格式**：直接传 ticker（MU、SPCX），字母开头自动识别；含点号的
   （如 BRK.B）按原样传递，个别特殊代码可能需要按数据源格式调整。
2. **数据源映射**：行情 东财(105/106/107)→腾讯(usXXX)→新浪(gb_XXX)；
   K线 东财 push2his→纳斯达克官网；指数 新浪 gb_$dji/gb_ixic/gb_inx；
   资金流 东财 fflow（与A股同结构，偶发限流）。
3. **不可用维度**：财务明细(F10)、龙虎榜、股东人数、主营业务构成、板块行情
   （A股专属）；美股新闻脚本暂不覆盖。这些维度在输出中缺省并提示，分析时
   用财报/公开信息补充。
4. **注意事项**：
   - 美股盘中运行时，东财K线最后一根为当日未走完bar，量比会失真；
     纳斯达克源为EOD数据（技术指标基于最近收盘），需与实时行情区分标注。
   - 上市不足60日的新股（如刚IPO的SPCX）没有MA60，技术面按已有均线判断。
   - 亏损股PE为负/无意义（如SPCX），估值改看PS、EV/EBITDA。
   - 美股特有风险维度：财报日历、锁定期解禁、做空情绪、监管/治理事件。

## 注意事项

1. 数据驱动，不编造；大盘优先，先看大盘再看个股
2. 技术术语用通俗语言解释；PE>500时转看PB/ROE/行业周期
3. "能买吗"给有条件判断，不给简单答案；支撑/压力位给具体价格
4. 盘后可用(腾讯/新浪 fallback)，但主力资金流向盘后不可用，标注数据来源
5. 新闻关注公告/中标/业绩预告等实质性内容，忽略市场情绪类资讯
6. 龙虎榜非所有股票都有，无上榜记录静默跳过
7. 股东人数关注趋势，结合股价位置判断"利好出尽"风险
8. 主营业务用于判断政策催化占比，避免概念炒作
9. 本机SSL证书链异常时脚本自动降级为不校验，正常环境仍走证书验证
