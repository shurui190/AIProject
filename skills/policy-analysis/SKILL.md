# 政府政策文件分析

> 本 skill 融合了 `policy-diff`(来源标注/缺口分析)、`research-synthesis`(主题提取/观察vs解读)、`web-research`(研究计划/子主题分解) 的方法论。

## 前置条件

- 网络可访问 WebSearch（搜索引擎）
- 必要时可低频单次访问 gov.cn 公开页面（WebFetch）
- 遵守 gov.cn 合规规则：低频单次、不绕过安全、不反复重试、优先搜索引擎

## 工作流程

### 第一步：制定研究计划

明确主问题 → 分解 2-5 个不重叠子主题 → 预期产出形态 → 确定报告层级。

### 第二步：数据获取

所有事实附来源标签贯穿始终：

| 标签 | 含义 | 可信度 |
|------|------|:---:|
| `[gov.cn 原文]` | gov.cn 直接获取全文 | 高 |
| `[gov.cn 摘要]` | 仅新闻通稿/摘要 | 中 |
| `[web search]` | 搜索引擎摘要 | 中 |
| `[model knowledge]` | 模型训练数据 | 需验证 |
| `[user provided]` | 用户直接提供 | 用户负责 |

**访问顺序**：WebSearch 搜索摘要 → 仅量化指标不足时低频单次访问 gov.cn → 404/403 立即停止不重试。

**数据清单**：发文字号、发文机关、日期、章节结构、专栏/附件量化指标、关键任务表述。

### 第三步：分层分析

#### 第一层：单文件深度解析

1. **文件元信息**：发文字号、发文机关、日期、规划依据 `[来源标签]`
2. **章节结构拆解**：总体要求→重点任务→保障措施，逐章逐节提取
3. **量化指标提取**（核心产出）：
   - 区分约束性（"必须达到"）和预期性（"努力实现"）
   - 量化优先：能写"7个规划"就不写"多个规划"
4. **重点任务摘要**：区分观察（文件中写了什么）和解读（这意味着什么），引用原文标注 `[原文]`
5. **关键信号**：Gap Analysis 思维——新提法/新目标/新机制，标注"新增/强化/延续/弱化"
6. **A股受益方向映射**：政策信号 → 受益产业 → 逻辑 → A股方向 → 代表标的 → 确定性
7. **催化剂日历**（标准化输出）：
   ```
   | 预期时间 | 催化剂 | 受益方向 | 确定性 |
   |---------|--------|---------|:---:|
   | 2026年H2 | 重卡充换电站招标启动 | 特锐德/许继电气 | ⭐⭐⭐ |
   | 2027年H1 | 碳核算体系细则出台 | 华测检测/国检集团 | ⭐⭐ |
   ```
   - 依据政策文件中的时间表述，标注"预计"时间
   - 确定性：⭐⭐⭐(明确时间表) / ⭐⭐(定性表述) / ⭐(仅提及方向)

#### 第二层：跨文件关联分析

1. **主题矩阵**：关键词在各规划中出现频次统计
2. **十四五→十五五演变追踪**：同一主题表述变化
3. **政策→产业→A股映射表**：从主题到标的完整链路

#### 第三层：综合策略报告

- 高优先级（明确量化目标+受益确定）
- 中优先级（有方向但缺具体资金安排）
- 待观察（仅审议通过，全文待公布）

### 第四步：输出报告

保存到 `output/<主题子目录>/`，命名格式 `{主题}_{报告类型}_{日期}.md`，所有数据标注来源标签。

## 第四步可选：联动 a-stock-analysis（重要）

当分析出受益标的列表后，**自动询问用户是否要对核心标的做个股深度分析**：

> "分析出以下受益标的：XX、XX、XX。需要我调用 /a-stock-analysis 对其中几只做个股深度分析（技术面、估值、资金面、入场时机）吗？"

询问时给出具体标的和预计分析维度，让用户选择。

## 分析原则

- 来源标签贯穿始终，不编造数据，缺失标注 `[未找到]`
- 区分观察与解读（`[原文]` vs `[推断]`），解读必须视觉可区分
- 量化优先，原文保留，不过度解读
- 合规：优先搜索引擎，低频单次访问 gov.cn，遇到拒绝立即停止

## 停止条件

| 条件 | 行为 |
|------|------|
| 搜索结果为空 | 换关键词重试 1 次；仍为空→标注 `[未检索到]` |
| WebFetch 404/403/失败 | 立即停止，标注 `[无法获取全文]`，不重试 |
| 规划仅有摘要/新闻通稿 | 标注 `[gov.cn 摘要]`，不编造细节 |
| 文件状态无法确认 | 标注 `[状态待确认]`，提醒用户核实 |
| 数据已齐全 | 停止工具调用，开始撰写报告 |
| 用户叫停 | 立即停止并发起确认 |
