# 政策主线 ETF 选择器

> 本 skill 将"政策解读 → 板块 → 个股"的链条压缩为"政策解读 → 主线 → ETF"，用板块贝塔替代个股阿尔法，
> 规避单一公司业绩/估值/财务造假风险。

## 何时触发

- 用户要求基于政策选 ETF / 基金 / 指数基金
- 需要判断某政策利好落地的板块工具
- 用户持有政策主线 ETF 想验证其有效性，或问是否该买/卖

## 核心原则（纪律优先）

### ✅ 流动性红线铁律
任何候选 ETF 若**当日成交额 < 0.5 亿（5000万元）** → 一律排除，不因题材好而豁免。
- 理由：成交额低 → 买卖价差大、冲击成本高、赎回/清盘风险（ETF 规模<1亿有清盘压力）
- 判定基准：以 **当日实时成交额** 为准，参考前 5 日均量（配合日均成交额复核）。

### ✅ 数据驱动不臆断
所有价格、成交量、成交额必须实时拉动，禁止引用旧数据或估算值。
**每个候选代码必须逐一验证代码真实存在且映射到预期跟踪指数**（防止代码写错 → 买到不相干品种）。

### ✅ 一条主线至少一个工具
宁可少选不可错配。没有合格流动性的主线宁可放弃，不强行凑数。

## 工作流程

### Step 1 — 锁定政策主线
调用 policy-analysis 思路（或直接用以下清单），提取 2-3 条确定性最高的主线（两会延续强调 + 十五五量化加码双重确认）：
- 打分维度：两会表述强度 × 十五五专项规划量化目标 × 直接受益面
- 输出格式：主线名 → 政策依据 → 受益产业方向 → 对应ETF所属指数类别

### Step 2 — 映射到 ETF / 指数
从候选池（`references/etf-candidates.md`）或行情软件按指数归类：
- 建议按 **跟踪指数** 归类（如中证人工智能主题、中证绿色电力、沪深300红利低波等），而非只看 ETF 名称关键词
- 同主线可选 1 个核心 + 1 个备选（备选用于流动性更好的替换判断）

### Step 3 — 实时数据核实（核心环节）
```bash
python skills/policy-etf-selector/scripts/fetch_etf_data.py "<代码1>,<代码2>,..."
```
- 核对字段：名称 / 现价 / 当日涨跌 / **成交额(亿)**
- 确认评级：极佳(≥10亿) / 优(≥3亿) / 及格(≥0.5亿) / ❗排除(<0.5亿)
- 若某代码结果为空 → 检查代码前缀（5/6开=head，其余=sz）或代码是否真实存在

### Step 4 — 组合构建
```
核心仓：政策确定性最高的 1-2 条主线对应的 ETF（各 40% 权重）
卫星仓：未来产业/预期差主线（20%）
防御仓：红利低波类（10-20%，市场回调时吸收波动）
```
权重可视风险偏好调整，但要提示用户：ETF 吃板块贝塔，无法规避系统性下跌。

### Step 5 — 输出报告
输出以下内容（保存到 output/<主题目录>/）：
1. 选定ETF表格：代码/名称/跟踪指数/成交额/评级/所属主线
2. 主线对应的政策依据一句话
3. 买入参考：回调至相关指数 MA20/MA60 分批，不打板追高
4. 风险提示：市场系统性风险、主线提前发酵后的兑现风险、ETF管理费差异
